两个待机页 · 方案一

日期时间页默认采用 B 版：时间 #F1BC74、日期 #D3DFDD、年份 #938573。可选 WHITE／MINT／CODEX，主题只调整本页颜色，连接顶栏保持绿色。日期时间页保留连接 header，把与 Session 工作时长相同的方正时钟放在中部，以 52px 高度显示，日期由原来的 18px 单行拆为 20px 年份和 36px 月日；月日下移至 y=177–221，减少下半屏空白，仍保留同一组日期信息。未知时间与日期继续使用占位，冒号静止。

Codex 用量页保留原来的窗口名称、剩余百分比与主机本地重置时间。每个窗口采用 88×110px 深紫面板，上方标题带略亮；中部大号百分比配合细进度条，下方显示重置时间，一周窗口保留日期与时间两行。单窗口保持原尺寸居中，未知读数保留「用量未知」；5 小时与一周分别判断剩余比例颜色。仅收到一周窗口时也可完整呈现。

待机两页仍按原规则每 10 秒轮播。非 Session 页的连接顶栏两侧采用更深的椭圆弧下边界，中央直线为 x=96–144、y=39，连接图标与正文位置保持原稿。其余导入页面保持原布局和示例信息；二期配对效果与产测用途在对应卡片中标注。

头部与轮换区的配色

所有业务页面默认底色统一为 #000000。Session 头部也使用纯黑，以 2px 弧形下边框划分头部和主体。下边框与目录共用 agent 配色：Codex #6550C8，Claude #D97757。圆润时钟、ASCII 目录与黑底状态边框保持现有布局。

上下文的 CTX 百分比面板与右侧 token 面板统一使用深蓝青：标题／上半行 #224657，正文／下半行 #152E3D。Agent 的 5H、WEEK 面板统一使用深紫：标题 #453254，正文 #2C223B。单档与双档保持同一种类的配色；健康比例的绿、琥珀、珊瑚文字不变，工作时长继续直接显示在黑底上。

固定和轮换

  • 固定：当前时间、目录名、左侧 Agent 图标与分割线、右上主状态、会话名。右下内容轮换时这些元素不移位。
  • ESP32-C3 目录仅显示可打印 ASCII，中文、emoji 及其他非 ASCII 字符各替换为一个 ?；固定中文状态文案保留。主状态内部为黑色，仅保留文字和固件边框动效。
  • 第一行是时钟，只显示时和分，中间冒号每秒闪一次。它不随工作时长冻结。
  • 等待输入和需要批准的边框复用 main/status.c 的双脉冲、周向柔光、边缘透明度算法：每 100ms 一帧，20 帧一周期。保留固件 143×48 的原始几何，显示时映射到本稿的状态块；不使用旋转锥形高光替代。柔光颜色分别为 #FFB02E 和 #FF5F7A。
  • 第四行顺序是工作时长 10 秒、有效 agent 用量 3 秒、有效上下文 3 秒。未知、未获取、窗口无效的读数不参与轮换。只有一档有效 agent 用量时，仅显示该档单块面板；0%／100% 都是有效值。没有有效用量时，停在工作时长。
  • 上下文左侧为 67×42px 的 CTX 面板，尺寸结构与 agent 用量一致，配色独立：上方 CTX 标题 11px，下方百分比 22px。两块上下文面板共用深蓝青主题。右侧 token 面板为 64×42px，与 CTX 面板间隔 6px，整体居中紧凑排列。token 面板两行各高 21px，共用一组外轮廓圆角，上半已用数值底色 #224657、文字 #E8F3FA，下半总量底色 #152E3D、文字 #AAC6D7；CTX 标题同用 #224657，百分比区域同用 #152E3D，标题文字 #C1D9E7。百分比按已用比例上色：低于 50% 绿，50–79% 琥珀，达到 80% 珊瑚。右侧两行是已用和总量，文本右对齐，总量不加斜杠。千位用大写 K；百万位用 M，数值保留 3 位有效数字，例如 1.23M、12.3M、123M。已用和总量各自选择单位；超出三位百万空间显示 >999M；未知上下文直接跳过；有效的 0% 正常显示。
  • agent 用量是剩余比例，颜色仍是 ≥50% 绿、≥20% 琥珀、低于 20% 珊瑚。两档同时显示时，左侧标题 5H、右侧标题 WEEK。用量区为 139×42px，两个独立圆角面板间隔 5px，两档统一使用深紫面板底色 #2C223B，标题带为 #453254，标题文字 #DECDEB。标题 11px，下方百分比 22px。只有 WEEK 或只有 5H 时，单面板保持 67×42px，居中显示在用量区；标题 11px、百分比 22px，均与双档相同。展示窗口由实际数据决定。未知档不参与显示，独立用量页仍按原规则显示未知占位。
  • 会话页之间仍按等待、完成、工作三组轮播，每页 10 秒。第四行按会话累计已展示时间，切回同一会话时继续原相位。10/3/3 秒明细轮换不重置会话页的 10 秒驻留，也不改灯环。
  • 顶部时钟使用 24px 圆润字体；工作时长在右下使用 32px 方正等宽字形、笔画加粗，无秒表图标，冒号常亮。工作、思考、等待输入、需要批准继续累加；状态未更新和完成态冻结并转灰。四位分钟字高收到 26px。
  • 会话名沿用 provider 色胶囊。Codex 紫，Claude 陶土色。贴着可视圆下沿，宽最多 88px，长名字直接省略。
  • 连接状态不画在这一页。断线仍走原来的连接页。
