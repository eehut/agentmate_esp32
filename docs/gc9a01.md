# GC9A01 软件开发参考手册

> 基于《GC9A01 DataSheet Rev 1.0 (2019-07-02)》整理，面向驱动/应用开发人员。
> 覆盖：像素组织(GRAM 结构、坐标系、数据格式)与软件操作方法(接口协议、命令、初始化、刷新流程)。

---

## 1. 芯片概览

| 项目 | 说明 |
|---|---|
| 型号 | GC9A01A（GalaxyCore） |
| 用途 | a-Si TFT LCD 单芯片驱动器（常见于 1.28" 圆形屏） |
| 分辨率 | 240 RGB × 240 |
| GRAM | 240×18×240 bit（每像素 18 bit，共 129,600 字节） |
| MCU 接口 | 3线/4线 SPI、8/9/16/18-bit 并口（8080-Ⅰ/Ⅱ） |
| RGB 接口 | 6/12/16/18-bit（需同时使用 SPI 配置寄存器） |
| 供电 | VCI 2.5–3.3 V（IOVCC 1.65–3.3 V） |

## 2. 像素组织

### 2.1 GRAM 与坐标系

- 每个像素 18 bit（R6G6B6），由 **(Page, Column) = (Y, X)** 定位。
- 有效显示区：X = 0x00–0xEF（0–239），Y = 0x00–0xEF（0–239）。
- GRAM 地址计数器在写入后自动按当前方向递增，超出窗口列则回卷到下一行。

```
(X,Y)=(0,0) ──────────────────► X (Column, 0x00~0xEF)
   │  (00,00)h (00,01)h … (00,13F)h
   │  (01,00)h (01,01)h … (01,13F)h
   ▼        …                    …
   Y  (13F,00)h …          (13F,13F)h
 (Page/Row, 0x00~0xEF)
```

### 2.2 窗口地址(Window Address)机制

写 GRAM 前先设定矩形窗口，之后连续写入的数据自动填充到窗口内，无需逐像素设地址——这是高效刷新的核心：

1. `CASET (0x2A)`：列起始/结束地址（X 范围，各 2 字节）
2. `RASET (0x2B)`：行起始/结束地址（Y 范围，各 2 字节）
3. `RAMWR (0x2C)`：随后连续写入像素数据
4. 写入达到 (EC,EP) 后回卷到 (SC,SP)，直到发任意其他命令终止

### 2.3 像素数据格式（MCU 接口）

通过 `COLMOD (0x3A)` 选择：

| COLMOD | 格式 | 说明 |
|---|---|---|
| 0x05 | **16-bit RGB565**（最常用） | `R[4:0] G[5:0] B[4:0]`，每像素 2 字节（大端） |
| 0x06 | 18-bit RGB666 | 每像素 3 字节 `R[5:0] G[5:0] B[5:0]` |
| 0x03/0x04 | 12-bit | 每像素 1.5 字节 |

RGB565 字节序（SPI 模式）：

```
第一个字节: R4 R3 R2 R1 R0 G5 G4 G3
第二个字节: G2 G1 G0 B4 B3 B2 B1 B0
```

### 2.4 扫描方向控制 —— MADCTL (0x36)

| Bit | 名称 | 作用 |
|---|---|---|
| 7 | MY | 翻转 Y（上下镜像，对应 GS） |
| 6 | MX | 翻转 X（左右镜像，对应 SS） |
| 5 | MV | 交换 X/Y（横屏/竖屏切换） |
| 4 | ML | 垂直滚动时地址顺序 |
| 3 | RGB | 面板色序 R-G-B |
| 2 | BGR | 面板色序 B-G-R（**多数 GC9A01 模组需置 1**，否则红蓝反色） |
| 1–0 | MH | 水平刷新方向 |

常用值：`0x00` 竖屏、`0xC0` 竖屏翻转、`0x60` 横屏、`0xA0` 横屏翻转（按模组实测调整）。

## 3. 软件操作方法

### 3.1 4线 SPI 协议

```
D/C 引脚: 0 = 命令字节, 1 = 数据字节
CS  片选，低有效
写时序: CS↓ → D/C=0 → 发命令 → (D/C=1 → 发数据…) → CS↑
每次 8 bit，MSB 在前，SPI Mode 0，常见时钟 ≤ 40 MHz（按模组而定）
```

伪代码：

```c
static void cmd(uint8_t c)            { dc_low();  spi_xfer(c); }
static void data(uint8_t d)           { dc_high(); spi_xfer(d); }

void gc9a01_write_cmd(uint8_t c, const uint8_t *d, int n) {
    cs_low();
    cmd(c);
    if (n) { dc_high(); for (int i=0;i<n;i++) spi_xfer(d[i]); }
    cs_high();
}
```

### 3.2 上电与初始化流程

```
1. 上电 VCI/IOVCC（同电源亦可），复位脚拉低 ≥10 µs 后释放
2. 延时 ≥120 ms（等待内部稳压稳定）
3. Sleep Out (0x11)，延时 120 ms
4. 发送厂商初始化序列（0xEF/0xEB/0xFE 解锁等，见下）
5. COLMOD (0x3A) = 0x05        // RGB565
6. MADCTL (0x36)、Frame Rate、Gamma 等
7. Display Inversion ON (0x21)  // 多数模组需要
8. Sleep Out 后 Display ON (0x29)
```

### 3.3 刷屏流程（窗口写入）

```c
void gc9a01_fill_rect(uint16_t x, uint16_t y, uint16_t w, uint16_t h,
                      const uint16_t *rgb565) {
    cmd(0x2A); data(x>>8); data(x); data((x+w-1)>>8); data(x+w-1);
    cmd(0x2B); data(y>>8); data(y); data((y+h-1)>>8); data(y+h-1);
    cmd(0x2C);
    dc_high(); cs_low();
    spi_dma_send(rgb565, w*h*2);     // 大端：高字节在前
    cs_high();
}
```

全屏刷新 = `fill_rect(0,0,240,240,buf)`，一帧 240×240×2 = **115,200 字节**。

### 3.4 常用命令速查

| 命令 | 名称 | 用途 |
|---|---|---|
| 0x01 | SWRESET | 软复位，需延时 ≥120 ms |
| 0x04 | RDDID | 读 ID（GC9A01 返回 0x009A01） |
| 0x09 | RDDST | 读显示状态 |
| 0x10 / 0x11 | SLPIN / SLPOUT | 进/出睡眠（进出各延时 120 ms） |
| 0x12 / 0x13 | PTLON / NORON | 局部显示 / 正常显示 |
| 0x20 / 0x21 | INVOFF / INVON | 显示反色关/开（多数模组需 ON） |
| 0x26 | GAMSET | 伽马曲线选择 |
| 0x28 / 0x29 | DISPOFF / DISPON | 屏灭 / 屏亮 |
| 0x2A | CASET | 列地址窗口（X0,X1，各 16 bit） |
| 0x2B | RASET | 行地址窗口（Y0,Y1，各 16 bit） |
| 0x2C | RAMWR | 写 GRAM |
| 0x2E | RAMRD | 读 GRAM |
| 0x30 | PTLAR | 局部显示区域 |
| 0x33 | VSCRDEF | 垂直滚动区域定义（TFA/VSA/BFA） |
| 0x34 / 0x35 | TEOFF / TEON | 撕裂效应信号关/开 |
| 0x36 | MADCTL | 扫描方向/色序控制（见 §2.4） |
| 0x37 | VSCSAD | 垂直滚动起始地址 |
| 0x3A | COLMOD | 像素格式（0x05=RGB565） |
| 0x51 / 0x53 | WRDISBV / WRCTRLD | 亮度 / 显示控制（按批次支持） |
| 0xB0 | RGB interface signal control | RGB 接口模式（RCM[1:0]） |
| 0xBA / 0xBC | DGM / RGBCLK | 模组相关，见数据手册 |
| 0xE0 / 0xE1 | PGC / NGC | 正/负伽马校正设置 |

### 3.5 防撕裂(TE)同步

- `TEON (0x35)` 开启后，TE 引脚在帧消隐期（V-sync 期间，可由参数选择 V-blank 前段/后段）输出脉冲。
- 推荐流程：等 TE 上升沿 → 立即启动整帧 DMA 写入，写入速度需快于面板扫描即可无撕裂。
- 若无 TE 引脚布线，可用"背光期间写、消隐期不可写"不可行时，退而求其次双缓冲或降低刷新频率。

### 3.6 电源状态机

```
Sleep In ──(0x11)──► Sleep Out ──(0x29)──► Display On
   ▲                                        │
   └──────────(0x10 / 0x01)─────────────────┘
进出 Sleep 前后各等 120 ms；Sleep 模式下 GRAM 内容保持
```

## 4. 调试检查清单

- [ ] 复位后延时是否足够（≥120 ms），初始化前屏是否进 Sleep Out
- [ ] SPI 模式 0、MSB first、命令前 D/C 拉低
- [ ] RGB565 颜色反了（红蓝互换）→ MADCTL 的 BGR 位（bit2）
- [ ] 画面镜像/旋转不对 → 调 MY/MX/MV
- [ ] 偏色/发灰 → 初始化序列是否匹配模组批次；是否需要 INVON (0x21)
- [ ] 局部花屏 → CASET/RASET 参数越界；DMA 缓冲长度非 w×h×2
- [ ] 撕裂 → 用 TE 同步或对齐消隐期写屏
