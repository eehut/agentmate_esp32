# 一期 UI 实现与验收记录

日期：2026-10-03。视觉依据：[全量视觉稿](design/session_states_board.html)；行为依据：[UI 需求](agentmate_ui_design_requirements.md)。

## 已实现页面与行为

| 页面 | 覆盖 |
|---|---|
| 启动 | 品牌、构建软件版本；前 300 ms 淡入，满 2 秒且协议监听就绪退出，最晚 5 秒；期间灯环熄灭，串口不阻塞 |
| 连接 | 等待主机、握手、同步；同步结束才显示已连接，不展示校时状态 |
| Session | working、thinking、waiting_for_input、permission_required、stale 与三种完成态；目录、Context 三态、长短键、长时长与页码 |
| Codex 用量 | 同一 metric 的 5 小时／一周剩余用量，单窗口、未知比例、未知重置时间；成功推送即启用，不依赖 Session 或活动时间 |
| 日期时间待机 | 主机本地 HH:MM／日期，缺时钟或偏移时占位；支持用量时与用量页每 10 秒轮播 |
| 设备信息 | SHOWINFO 拉起／续期／关闭；八行身份、亮度、日期时间；告警关闭；保留进入时灯效 |

当前规则（替代下文历史记录）：等待授权／输入 > 完成态 > 工作／思考／stale > 待机；所有子页 10 秒。同组新成员仅加入轮播，LED 跟随当前会话。EVENT 不增加独立驻留或闪光。配对二期不启用，现有产测保持原流程。

## 模块与资源

- `agentmate_status`：主状态配色、10 fps 相位、圆角几何与 8 种边框动效；与数据刷新及计时解耦。
- `agentmate_led`：纯状态动画模块，可注入随机数验证追逐换向和精确亮灭边界。
- `agentmate_ui_state`：可独立测试的组选页、Session 轮播与统一待机调度。
- `agentmate_ui_render`：场景元素、UTF-8 文本度量、4-bit 灰度合成与局部重绘；仅一个 240×32 RGB565 缓冲，与产测共用。
- `agentmate_ui`：各页布局、非阻塞启动／转场、信息页灯效保持及 20 Hz 灯效调度。
- `agentmate_text`：UTF-8 校验、百分号编码、目录长度校验和有符号偏移解析。
- `assets/ui/`：矢量源、中文文案字表与时序／字体 manifest；`agentmate_ui_assets` 是生成结果。
- `assets/provider_icons/`：provider 图标源与 36 px BMP，保留原始服务端 Codex 图标，UI 使用 codex_ui.svg。

固定文案使用对应字号的字形子集，目录覆盖 ASCII 与 GB2312。字体为画板引用的 PingFang SC／SF Rounded 和 Helvetica Neue Light 数字；来源文件哈希见 manifest，不将字体文件复制进固件。待机数字 45 px；Session 数字常用 30 px，超宽时 22 px。用量百分比 26 px 数字作横向收窄，以在 84 px 双列中完整显示。信息页值使用固定 8 px 字符宽度，确保完整日期与 ID 不截断。

生成与构建：

```sh
python tools/generate_ui_assets.py
python tools/generate_provider_icons.py
. "$HOME/esp/esp-idf/export.sh"
idf.py build size
```

生成工具需要 Pillow／CairoSVG；非 macOS 可通过参数指定字体源。常规固件构建使用已提交资源，不需要安装生成工具。

[实际 C 渲染器生成的 240×240 页面预览](design/firmware_preview.png)不包含设计辅助线。主机测试使用真实页面构建器和块渲染器，屏幕与 LED 硬件接口替换为测试实现。

## 服务端协议适配（已完成）

协议主版本保持 **1**，之前版本未发布，不协商旧格式；完整定义见 [AT 指令指南](agentmate_at_command_guide.md)。

1. 每条 SESSION 追加 `project_name`：basename，百分号编码 UTF-8，解码后最多 64 字节；未知时保留空字段。GET 同样有此字段；目录变化要递增 rev。编码可用 `urllib.parse.quote(name, safe='-_.~')`。过长 basename 在服务端按 UTF-8 字符边界裁至 64 字节。
2. TIME 改为 `unix_ms,utc_offset_minutes`。设置响应多一项偏移，查询多一项偏移。不要将本地时间误传为 Unix 时间。
3. 每条 USAGE 追加 `reset_utc_offset_minutes`；按主机时区在 reset_at 时刻计算，不能直接复制当前偏移。未知偏移用 `-`。window_key 最多 16 字符，支持 primary／secondary。
4. 百分比未知时保留可获得的 window_seconds、reset_at 和偏移，不把已知窗口时长清零。采集失败／available=false 仍使用 USAGECLEAR。
5. SHOWINFO 使用显式秒数，常用 10、关闭 0；查询是串口状态，不显示倒计时。
6. 发现后顺序：HELLO → TIME → SYNCBEGIN → SESSION → SYNCEND → USAGEBEGIN／USAGE／USAGEEND（无用量时 USAGECLEAR）；保持心跳少于 30 秒间隔。重连接完整同步，不重放历史事件。
7. 每 30 分钟及主机时区／夏令时变化时重新发送 TIME，刷新各窗口的重置偏移。读写缓冲须容纳 512 字节 AT 行；无效旧字段数量返回 INVALID_ARG。
8. 用量刷新使用 USAGEBEGIN／USAGE／USAGEEND 原子替换 provider；暂存期间继续显示旧页，失败不发布部分数据。窗口标题为 19 px，不绘制横线或重置标签；5 小时只显示 HH:mm，一周日期和时间分两行。
9. TFTBRIGHT／LEDBRIGHT 设置与查询统一为 0～100 的整数百分比，与面板及设备信息页一致。驱动和 NVS 保留 0～255，已有设备升级保留实际亮度。

已在 `/Users/einsn/work/agentmate_service` 完成以上适配，协议主版本保持 1，移除旧固件状态降级。面板设备配置窗可显示 10 秒／关闭信息页；对应 `POST /v1/devices/{device_id}/show-info` 接收 seconds（0～60，缺省 10）。完整字段、时区重载和验证记录见服务端 `docs/device_ui_protocol.md`。
